# 使用指南

[快速上手](../README.zh-CN.md) · [English](USAGE.en.md)

## 代理地址与端口

在 **本机代理地址** 中填写代理软件实际提供的 HTTP(S) 监听地址，然后保存。**7890 只是默认端口，可以修改。**

| 示例 | 含义 |
| --- | --- |
| `http://127.0.0.1:7897` | 本机 HTTP 代理，端口 7897 |
| `http://localhost:8080` | 本机 HTTP 代理，端口 8080 |
| `https://127.0.0.1:8443` | 本机 HTTPS 代理；代理证书必须受信任 |
| `http://[::1]:8080` | IPv6 环回 HTTP 代理 |

协议指的是“客户端如何连接代理”，不是模型 API 的协议。HTTPS API 通常可以通过 HTTP CONNECT 代理访问，不必把代理地址改成 https。

当前不支持 SOCKS、PAC、远程/局域网代理地址或代理 URL 中的用户名密码。若代理软件只有 SOCKS 端口，需先开启 HTTP 或兼容 HTTP 的 mixed 监听；仅把 socks5 字样改成 http 不会转换协议。API 域名栏只填主机名，代理端口填写在本机代理地址栏。

## Provider 与域名规则

候选来自 DSH provider 目录和脱敏配置，提取显式 provider/model baseURL 的主机名；目录默认地址会标注来源。未配置的休眠目录项不会列入。动态地址、环境变量地址或接口未提供的地址需要手动填写。

添加只改变草稿，保存后才生效。刷新 provider 列表保留草稿；provider 地址后来变化不会自动修改已保存规则。多个 provider 共用域名时，也共用该域名的规则。

最多 32 个域名共用一个本机代理地址。默认精确匹配；包含子域名是作用于全部域名的公共开关。域名栏不接受协议、路径、端口或通配符。

## 路径与节点

插件决定哪些域名交给本机代理；代理软件的规则和策略组决定出口节点。未匹配请求沿用原路径，原路径可能已经受系统代理、TUN 或环境变量影响。

检查连接依次对每个草稿域名的 HTTPS 根路径发送无鉴权 HEAD，每项超时约 8 秒。HTTP 401/404/503 也表示收到了响应，不能据此判断鉴权或模型成功。检查不会保存草稿或发起模型测试。

## 最近调用

开启记录最近调用并保存，正常使用 DSH，再到实际路径或最近表现页刷新。不额外发送测速请求。最多保留 100 次内存记录；关闭、清空、卸载或重启后删除，不导入历史会话。

“已交给代理”只证明插件选用了该代理，不证明网络成功或最终节点。“原有路径”不等于直连；“未观察到”表示未知。每次调用最多保留 16 条主机路径，分发次数不能充当重试次数。配置编号用于当前进程内对照规则变化。

## 指标口径

| 指标 | 定义 |
| --- | --- |
| 首内容等待 | 从开始消费模型流，到首个非空文本、推理或工具参数增量；不是 HTTP 首字节，也不一定是可见回答首字 |
| 生成速度 | 适配器输出 token ÷ 首个 block-start 到最后一个 block-end 的跨度；只在成功完成且数据充分时展示 |
| 调用总耗时 / 端到端速度 | 单次模型调用，含初始等待，不含随后工具执行 |
| 最长内容间隔 | 相邻内容增量的最大间隔；不足两个增量时未知，不包含首内容前等待和末尾静默 |
| token 用量 | 适配器报告值；缺失字段显示未知 |
| 重试次数 | 尚无可靠关联，显示未知 |

客户端计时可能包含适配器处理和消费等待。不同任务、上下文、输出长度、缓存条件下的数据不可直接当成公平对比。不保留对话正文或密钥，但 provider、模型和域名标签可能暴露内部服务名称。

## CLI 与升级

```sh
node bin/cli.js doctor --domain api.example.com --proxy http://127.0.0.1:7897
```

请替换示例域名。退出码：0 传输可达，1 传输失败，2 参数无效。独立 CLI 不能证明运行中的 DSH 已启用插件。

Desktop 使用内置插件管理器安装、升级和卸载。替换包前等待任务结束，完成后重启并检查保存值。DSH 卸载后保留配置覆盖项；希望重装后保持关闭时，先关闭分流并保存。不要整份覆盖无关 profile 配置。

Web CLI profile 可使用：

```sh
dsh plugin --profile web add /absolute/path/package.tgz
dsh plugin --profile web remove dsh-domain-proxy
```

启用本插件前应停用旧的全局分发脚本。仅覆盖 DSH 全局 Fetch/Undici 路径，私有网络栈、WebSocket、子进程不作保证。见[安全说明](../SECURITY.md)和[验证范围](VALIDATION.md)。

## 复现

    npm ci --ignore-scripts
    npm test
    npm run check
    npm run test:dsh
    npm run pack:local

test:dsh 默认使用 macOS 已安装 Desktop 自带可执行文件与 CLI；可通过 DSH_TEST_EXECUTABLE 与 DSH_TEST_CLI 指定其他受测路径。每次创建独立 DSH_HOME，只在该目录安装、配置、重启与卸载，结束时停止测试进程。

本地网络测试生成临时证书与本机代理，测试 CA 只用于测试 Agent，生产 TLS 校验保持开启。测试与构建输出写入忽略的 artifacts/，不进入 npm 包或 Git。

## 本地预览

scripts/run-dsh-preview.mjs 启动隔离 Web profile。先将本地包安装/链接到 artifacts/dsh-home/profiles/web。一次性引导将登录令牌保留在进程内，通过本机 Cookie 建立会话，不把令牌写进输出或文件。停止时只关闭该脚本创建的进程。
